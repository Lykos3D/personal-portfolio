Projects

I have worked on several projects while studying Computer Science, from computer graphics projects to compression algorithm implementations. Below is a brief summary of several projects I have worked on.

j-- Programming Language

  • Implemented the j-- programming language, a subset of the Java programming language which compiles to the Java Virtual Machine (JVM)
  • Implemented a handcrafted Scanner and Parser to scan user input and create an abstract syntax tree (AST) representation of the source program
  • Implemented logic for semantic analysis to ensure no user semantic errors and handled code generation

Particulum: Particle Simulator

  • Implemented a particle system simulation in JavaScript using three.js
  • Uses transformation matrices to simulate the movement of stars and other particles for various different space structures, from eliptical galaxies to quasars
  • A trial of the simulator is available here.

Hamming Error-Correcting Code Algorithm

  • Implemented the Hamming(7, 4) error-correcting code algorithm in C, which is useful in fixing errors that may occur during data transmission
  • Utilizes bitwise operations to calculate parity of data bits and store the calculated parity and data bits into seven different disks
  • The aforementioned parity bits are consulted to identify and flip any corrupted bits that may have occurred during data transmission

Huffman Data Compression Algorithm

  • Implemented the Huffman data compression algorithm in C, which compresses text files into reduced-size binary files
  • Reads an input file, constructs a binary tree to generate unique binary codes for each character, and utilizes bitwise operations to write the text file to a binary file utilizing the codes

Percolation Simulation

  • Implemented a percolation system API in Java, useful in applications such as fluid dynamics and circuit analysis
  • Utilizes a union-find data structure to create an n by n grid, run a percolation simulation, and compares the experimental system results with probabilistic models
